# Decision Diagnosis and Evidence Planning

## Inputs

Decision question, scope, time horizon, constraints and known evidence.

## Deliverables

Answerable question tree, leaf-level evidence plan and prioritized next investigation.

## Applied request

~~~text
Investigate falling operating profit. Decompose revenue/cost drivers, attach evidence to each leaf and include a disconfirming check.
~~~

## Acceptance criteria

Branches use consistent levels; causes remain hypotheses until supported; priorities connect to the decision.
