# Retrieval design cases

For an answer about an approved policy, verify the policy identifier, lifecycle state and effective date. A draft that matches the query more closely can still rank below the effective approved document. If two approved sources disagree, preserve each claim and its date and scope instead of averaging them.

For each fixture record query, caller, expected source and anchor, allowed versions, answer criteria and expected abstention or conflict behavior. Include exact identifiers, paraphrases, missing evidence, superseded versions, deletion and denied cross-tenant retrieval. Check that result expansion, snippets and cached output obey the same access rules.

Measure candidate coverage at the requested retrieval depth when you have labeled evidence. Separately check whether generated claims are supported by cited sources and whether a citation opens to the correct location. Record fixture count, skipped cases and index/version settings. Use a deliberately narrow evidence slice only when it still supports the complete claim.
