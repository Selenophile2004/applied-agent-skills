# Consulting Storylines and Slide Manifests

## Inputs

Audience decision, agreed content/scope, evidence ledger, language and output format.

## Deliverables

Document brief, argument spine and slide manifest with ID, message, evidence/status, visual form and unresolved input.

## Applied request

~~~text
Turn approved proposal modules into an executive storyline; specify each slide's action title, evidence and visual form.
~~~

## Acceptance criteria

Each slide advances one supported message; titles alone express the argument; on-slide copy and author notes remain separate.
