# Proposal storyline and production handoff

Retain accepted problem/situation, chosen solution, scope, deliverables, content version and unresolved decisions. Identify disputed claims rather than manufacturing approval.

## Three levels
Audience decision -> connected argument -> individual slide message.
An action title states a supported conclusion, not merely a topic label. A quantified benefit requires evidence.

## Manifest
Slide ID, narrative role, action title, core content, evidence ID/status, visual form, production note and input status. Separate on-slide copy from speaker/author notes. Charts need real data and units; diagrams need defined relationships.

## Evidence
For material claims retain source handle/type, date/period, geography, definition, units and limitations as applicable. Distinguish facts, analysis, assumptions and recommendations. Credentials/testimonials require actual supplied or approved evidence.

## Review and revision
Read titles alone to test the argument. Read content without narration for audience clarity. The summary communicates the recommendation rather than repeating the contents list.

Preserve stable slide IDs and accepted messages. Scope/fee/outcome changes expose upstream dependencies. Trace conclusions to support and keep an unresolved-input register instead of fabricating commitments.
