# Governed analytics cases

Example question: why did gross margin decline? Confirm the approved gross-margin formula, net sales and gross-profit definitions, fiscal calendar, currency, division and included locations. Use the same filters for numerator and denominator. Recompute the aggregate ratio from totals where the metric calls for weighting. Distinguish a verified decline from possible drivers and from a causal conclusion.

Reconcile metric values against an authoritative report or control query at the same grain, period, filters and refresh point. Investigate differences in calendar boundaries, return treatment, joins, currency conversion and security filters before interpreting a discrepancy. Record differences and tolerance rather than rounding them away.

Evaluation fixtures can cover ambiguous measures, weighted versus simple aggregation, duplicate joins, partial periods, missing rows, zero denominators and unauthorized tenants. Test using actual effective identities or authorized mocks and clearly label which. Return definitions, units, dates, filters, query/source handle, reconciliation and unresolved limitations.
